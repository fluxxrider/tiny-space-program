# AI 2027 — an explainer film

A 7 min 52 s cinematic explainer of **[AI 2027](https://ai-2027.com)**, the scenario published in April 2025 by
Daniel Kokotajlo, Scott Alexander, Thomas Larsen, Eli Lifland and Romeo Dean (AI Futures Project).
It follows the scenario month by month, from the first stumbling agents in mid-2025 to the Oversight
Committee's vote in October 2027, then plays both endings (Race and Slowdown) and an epilogue.

This is an unofficial fan explainer. Every frame is generated by WebGL shaders and Canvas2D, and every note of the
score is synthesized in JavaScript. There are no samples, stock footage or prerecorded audio.

## Watch

- **Video:** `out/ai-2027-film.mp4` after rendering (see below).
- **In the browser:** `node tools/serve.mjs` from the repo root, then open
  <http://localhost:8765/films/ai-2027/>. The film renders live and is synced to the soundtrack.
  Space plays and pauses, the arrow keys skip 5 s, F toggles fullscreen.
- **Single-file page:** `dist/ai-2027.html` plus `dist/score.mp3`. Serve them together from any static host.

## How it is built

| Part | Files |
|---|---|
| Master clock: 96 BPM, 188 bars, picture and music share the grid | `src/structure.js` |
| Every on-screen line and the AI R&D progress-multiplier keys | `src/script.js` |
| Picture events the music hits (votes, glitches, rocket launches) | `src/timing.js` |
| Renderer: HDR targets, bloom, anamorphic streak, ACES, grain, letterbox | `src/engine/*.js`, `src/film.js` |
| Captions, chapter cards, HUD | `src/overlay.js`, `src/engine/text.js` |
| 26 scenes (datacenter ray-tracer, dotted globe, 300k-particle iris, orbital sunrise…) | `src/scenes/*.js` |
| DSP library (band-limited oscillators, filters, FFT convolution reverb, limiter, LUFS) | `audio/dsp.js` |
| Instruments: piano, strings, organ, formant choir, braams, taiko, Shepard tone, SFX | `audio/instruments.js` |
| The score (D minor theme and its D major transformation) | `audio/score.js` |
| Web player | `src/player.js`, `tools/build-artifact.mjs` |

The film is a pure function of time: `film.render(t)` draws the exact frame for `t` seconds, so the
offline renderer, the scrubber and the tape-rewind effect (which replays the Race ending backwards) all use
the same code path.

## Rebuild

From the repository root:

```sh
npm install                                             # puppeteer-core + esbuild (repo deps)
node films/ai-2027/tools/prepare-assets.mjs             # fonts + globe data (already committed in src/data)
node films/ai-2027/audio/render-score.mjs               # → films/ai-2027/out/score.wav (~1 min)
node films/ai-2027/tools/build-artifact.mjs             # → index.html, dist/ai-2027.html, dist/score.mp3
node films/ai-2027/tools/render-video.mjs --fps 24 --query grain=0.4 \
     --audio films/ai-2027/out/score.wav --out films/ai-2027/out/ai-2027-film.mp4   # ~2 h on 4 CPU cores
```

`render-video.mjs` drives headless Chromium (SwiftShader WebGL2) frame by frame, streams raw frames to
ffmpeg, and writes resumable 10 s segments. `--stills` and `--contact` render single frames and contact
sheets for review. `node films/ai-2027/audio/dsp.test.mjs` runs the DSP tests.
